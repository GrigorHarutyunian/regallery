Questions before you install

Does Re Gallery replace my existing Shopify alt text, or only fill in blanks?

Re Gallery only generates metadata for fields that are currently empty — it does not overwrite alt text you've already written manually. Your existing content stays exactly as you left it.

Can I edit what the AI generates?

Yes. Every generated alt text, title, and description is a normal editable text field. Adjust tone, add brand language, or work in a specific SEO keyword — the AI is a starting point, not a lock-in.

What counts as one AI generation?

One generation = one field written for one image. Generating a title, alt text, and description for a single photo uses 3 generations. Your monthly allowance resets at the start of each billing period.

Will this slow my Shopify store down?

No. AI generation happens when you click the button in the admin — not on storefront page loads. The front-end gallery is lightweight with lazy loading built in, so it won't affect your Core Web Vitals or store speed scores.

Does it work with my Shopify theme?

Re Gallery is built as a Shopify 2.0 app block and works with every Online Store 2.0 theme — including Dawn, Impulse, Prestige, and all major premium themes. You can drop galleries anywhere on any page without touching code.

Do I need to keep a separate alt text plugin?

No. Re Gallery handles gallery layouts and AI image SEO in a single install. You can cancel your separate alt-text app — and the monthly fee that comes with it.
